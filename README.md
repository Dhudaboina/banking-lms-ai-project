# Banking Loan Management System — AI-Powered Testing

**Project Status:** Planning and Requirements Phase

## 1. Project Overview

This project simulates the end-to-end lifecycle of a banking loan, from customer registration and loan application to approval, EMI calculation, repayment tracking, and loan closure.

It combines Java development, banking business workflows, software testing, performance testing, defect management, CI/CD, and AI-assisted testing.

## 2. Technology Stack

- **Backend:** Java and Spring Boot
- **Frontend:** HTML, CSS, JavaScript
- **Database:** PostgreSQL and SQL
- **Project Management:** Jira
- **API Testing:** Postman
- **Unit Testing:** JUnit and Mockito
- **UI Automation:** Playwright
- **Performance Testing:** Apache JMeter
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **AI Integration:** Python and Model Context Protocol (MCP)

## 3. Planned Features

1. Customer registration and validation
2. Loan application submission
3. Loan eligibility validation
4. Loan approval and rejection workflows
5. EMI calculation and repayment schedules
6. Simulated repayment management
7. API, database, functional, and UI automation testing
8. Jira defect tracking and regression testing
9. JMeter load and performance testing
10. Python-based AI/MCP testing integration

## 4. End-to-End Workflow

Requirements → Design → Development → Functional Testing → Automation Testing → Defect Management → Performance Testing → CI/CD → AI/MCP Integration → Final Demonstration

## 5. Project Documentation

The repository will include business requirements, loan lifecycle diagrams, architecture, database design, API documentation, test plans, test cases, defect reports, performance results, setup instructions, and interview preparation notes.

## 6. Current Status

The project is in the requirements and planning phase. Features, test results, and performance metrics will be documented as they are implemented and verified.

## 7. Disclaimer

This is an educational portfolio project using fictional customer data and simulated financial operations. It is not affiliated with a bank and is not intended for real lending decisions or payment processing.
